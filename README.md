# Giao thương số Thôn 6

Landing page tĩnh dành cho GitHub Pages, phục vụ mô hình ứng dụng công nghệ số trong sản xuất, kinh doanh tại thôn.

## Cấu trúc

- `index.html`: trang chính.
- `css/style.css`: giao diện.
- `js/app.js`: nạp và hiển thị dữ liệu, tìm kiếm hộ kinh doanh.
- `data/data.json`: dữ liệu mẫu về sản phẩm và hộ kinh doanh.
- `assets/`: chỗ để thêm ảnh sản phẩm, logo và tài nguyên khác.

## Chạy trên GitHub Pages

1. Tạo repository public trên GitHub.
2. Upload toàn bộ thư mục này hoặc các file giữ nguyên cấu trúc thư mục.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch → main → / (root)**.
5. Lưu và mở địa chỉ GitHub Pages được cấp.

## Cập nhật dữ liệu

Thay dữ liệu mẫu trong `data/data.json` bằng dữ liệu đã được xác nhận của thôn. Không nhập thông tin cá nhân nhạy cảm hoặc thông tin chưa được phép công khai.

## Lưu ý

Trang hiện là website tĩnh. QR thanh toán, form đặt hàng, bản đồ, tài khoản quản trị và cơ sở dữ liệu trực tuyến có thể tích hợp ở bước tiếp theo.
